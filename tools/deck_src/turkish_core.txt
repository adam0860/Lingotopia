# Lingotopia — Turkish core vocabulary source
#
# Format (pipe-delimited, one entry per line):
#   lemma | pos | english gloss | sentence_tr | sentence_en [ | sentence2_tr | sentence2_en ]
#
# Ordering here is the PEDAGOGICAL frequency order (lemma-level). The build
# script additionally attaches the OpenSubtitles surface-form corpus rank where
# one exists, for reference — see tools/build_deck.py and README.md for why the
# two differ.
#
# pos codes: n=noun adj=adjective v=verb adv=adverb pron=pronoun
#            num=numeral part=particle conj=conjunction post=postposition
#            interj=interjection

günaydın|interj|good morning|Günaydın! İyi uyudun mu?|Good morning! Did you sleep well?
teşekkür|n|thanks|Teşekkür ederim.|Thank you.
lütfen|adv|please|Lütfen bana yardım et.|Please help me.
özür|n|apology|Özür dilerim, geç kaldım.|I'm sorry, I'm late.
tamam|interj|okay, all right|Tamam, anlaştık.|Okay, we agree.
efendim|interj|pardon?; yes? (polite response)|Efendim? Duyamadım.|Pardon? I couldn't hear.
hoş geldiniz|interj|welcome|Hoş geldiniz, buyurun.|Welcome, please come in.
görüşürüz|interj|see you|Görüşürüz, kendine iyi bak.|See you, take care.
